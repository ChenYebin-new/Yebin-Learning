# Yebin-Learning

用来存放自 2026.8.9 日起的学习内容。

## 学习计划

第一部分准备先学习 HTML。

## 已完成内容

### HTML 基础

- `web-projects/test-site`：建立基础 HTML 页面并插入本地图片。
- `web-projects/first-website`：练习标题、图片、段落、列表和超链接等常用 HTML 元素，使用 CSS 设置字体、颜色、排版、边框和图片布局，并用 JavaScript 实现图片切换与用户名的本地保存。

### 个人技术博客 v0.1

- `personal-blog`：使用 HTML、CSS 和原生 JavaScript 构建的多页面个人学习博客，包含首页、关于、学习笔记、项目和联系页面，以及主题切换、主题偏好保存与学习笔记搜索功能。站点不公开个人联系方式或其他敏感信息。

### 星旭风机企业门户网站 v0.1

- `xingxu-fengji-website`：使用 HTML、CSS 和原生 JavaScript 构建的企业宣传网站，面向工业通风设备本地客户，包含首页、产品分类与详情、服务流程、电话和微信咨询入口，并为后续补充真实产品及工厂图片预留了清晰位置。
