# Yebin-Learning

用于记录自 2026 年 8 月起的开发与安全学习内容。

## 学习计划

当前先巩固 HTML、CSS、JavaScript 与 Git 基础，再逐步进入 Vue、后端服务和安全开发实践。

## 已完成内容

### HTML 基础

- `web-projects/test-site`：建立基础 HTML 页面并插入本地图片。
- `web-projects/first-website`：练习常用 HTML 元素、CSS 页面样式与 JavaScript 基础交互。

### 个人技术博客 v0.2

- `personal-blog`：使用 HTML、CSS 与原生 JavaScript 构建的多页面个人学习博客。
- 包含首页、关于我、学习笔记、项目与联系页面，以及主题切换、主题偏好保存和学习笔记搜索。
- 新增两个站内项目成果页，展示个人技术博客与星旭风机企业宣传门户网站的实现重点、公开页面截图和线上入口。
- 站点不公开个人联系方式、住址、真实照片或其他敏感个人信息。

### 星旭风机企业门户网站 v0.3

- `xingxu-fengji-website`：使用 HTML、CSS 与原生 JavaScript 构建的企业宣传门户网站。
- 包含企业宣传首页、产品分类与详情、服务流程、响应式布局与咨询交互区域；当前已配置企业咨询电话与地址，并为后续补充真实产品和企业素材预留结构。
- 新增真实门店照片与离心风机实拍图集，首页和离心风机详情页均支持叠放式点击切换动画。
- 接入企业微信咨询二维码与轴流风机实拍图集；产品中心支持整卡点击跳转，并保留键盘访问焦点样式。
