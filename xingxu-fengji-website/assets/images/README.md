# 网站图片资源说明

网站运行时只引用 `optimized/` 中的 WebP 文件。企业提供的原始图片保存在项目根目录的 `原始图片素材/`，不得覆盖、移动或删除。

`favicon.ico` 根据网站现有的 X 品牌标记制作，仅作为浏览器页签图标，不属于企业实拍素材。

## 目录与用途

- `optimized/hero/`：首页门店图集。
  - `*-720-v3.webp`：手机和常规屏幕优先使用。
  - `*-v2.webp`：高分辨率屏幕候选图。
- `optimized/cards/`：产品中心卡片缩略图，避免卡片加载详情页大图。
- `optimized/galleries/`：离心风机和轴流风机详情图集。
  - `*-720-v3.webp`：常规视口候选图。
  - `*-v2.webp`：较高清晰度候选图。
- `optimized/wechat/`：企业提供的真实微信二维码，保持完整比例，不裁剪、不再次有损压缩。

## 页面与分享图

- 首页分享图复用第一张门店实拍。
- 离心风机、轴流风机分享图使用对应产品实拍。
- 排烟风机、除尘风机尚无实拍，分享图使用门店实拍，不将其标注为产品图片。
- 页面内的门店图、卡片图和详情图分别使用对应尺寸，不能相互替代。

## 后续补充规则

1. 新素材先保存在 `原始图片素材/` 的对应子目录。
2. 网站使用副本统一转换为 WebP，并使用英文、类别清晰且带版本号的文件名。
3. 产品卡片和详情页分别生成合适尺寸，避免卡片加载详情大图。
4. 没有真实素材的产品继续显示“实拍资料待补充”，不得使用虚构企业实景。
5. 新增图片时同时补充固有宽高、替代文字、响应式候选图和用途说明。
