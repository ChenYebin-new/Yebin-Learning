# 网站图片资源说明

企业实拍和二维码只引用 `optimized/` 中的 WebP 文件。企业提供的原始图片保存在项目根目录的 `原始图片素材/`，不得覆盖、移动或删除。

`favicon.ico` 是根据网站现有 “X” 品牌标记生成的浏览器页签图标，不属于企业实拍素材。

## 目录用途

- `optimized/hero/`：首页门店图集。
  - `*-720-v3.webp` 是手机与常规屏幕优先使用的版本。
  - `*-v2.webp` 是高分辨率屏幕候选版本。
- `optimized/cards/`：产品中心卡片缩略图，不能用详情大图代替。
- `optimized/galleries/`：离心风机和轴流风机详情图集。
  - `*-720-v3.webp` 是常规视口候选版本。
  - `*-v2.webp` 保留较高清晰度并作为高分辨率候选版本。
- `optimized/wechat/`：企业提供的真实微信二维码，保持完整比例，不裁剪。

## 后续补充规则

1. 新素材先保存到 `原始图片素材/` 对应子目录。
2. 网站使用副本统一转为 WebP，并使用英文、类别清晰且带版本号的文件名。
3. 产品卡片和产品详情分别生成合适尺寸，避免卡片加载详情大图。
4. 没有真实素材的产品继续显示“实拍资料待补充”，不得使用虚构企业实景。
