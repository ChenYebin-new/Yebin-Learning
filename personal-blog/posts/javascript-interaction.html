用 JavaScript 让页面回应用户

学习笔记 · v0.1 示例内容

JavaScript 负责响应用户动作、处理数据，并更新页面状态。本项目的主题切换和笔记搜索都是从这个思路出发的。

从 DOM 开始

DOM 让脚本可以读取和修改页面元素。找到元素后，可以监听点击或输入事件，并根据结果调整页面内容和样式。

搜索应给出反馈

笔记搜索会比较用户输入与每篇文章的标题、摘要和标签。没有匹配时，页面会给出明确提示，而不是留下一片空白。

本地保存主题偏好

主题选择保存在 localStorage 中，因此刷新页面或访问其他页面后仍会保持用户的偏好；首次访问则跟随系统主题。

下一步练习

  • 为按钮添加点击事件。
  • 使用事件对象读取输入框内容。
  • 为交互添加无结果和错误状态。
