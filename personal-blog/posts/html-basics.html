HTML · 基础

从网页结构开始理解 HTML

学习笔记 · v0.1 示例内容

HTML 的价值不在于“让文字显示出来”，而在于把网页内容组织成浏览器、搜索工具和读者都能理解的结构。

先搭建文档骨架

每个页面都从 <!doctype html>、<html>、<head> 和 <body> 开始。head 放置页面标题和样式等元信息，body 放置用户能够看到和操作的内容。

优先使用语义化元素

当内容属于网站头部、导航、主要内容或页脚时，应优先使用 header、nav、main、footer。这会让代码更容易维护，也有助于辅助技术理解页面。

下一步练习

  • 用语义化标签重写一个个人介绍页面。
  • 为图片补充有意义的 alt 文本。
  • 用 label 关联表单字段，提高可访问性。
